# GitHub setup

Upload the `delta/` folder to your public repository. Expected source URL:
`https://raw.githubusercontent.com/rafingepet-cyber/roblox-multimap-loader/main/delta/NEXUS-DELTA.lua`

Edit `API_URL` inside `delta/NEXUS-DELTA.lua` to:
`https://nebul.rf.gd/api.php`

If using another domain/repository, update the URL constants accordingly. Host the accompanying PHP/API files separately on InfinityFree.
